# Buratino

- The CLI is `./buratino/bin/buratino`; project and command details are in [README](README.md).
- Buratino source is in `src/buratino`; editable Cabineteer source is in `vendor/cabineteer`.
- Furniture authoring choices and current examples are in [the designing guide](docs/designing.md).
- Rectangular models use `SpaceModelSpec` or Space assemblies; profiled models use `ProfileAssemblySpec`.
