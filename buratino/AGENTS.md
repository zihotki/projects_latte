# Buratino

- Work from the repository root. Use `./buratino/bin/buratino` for setup,
  checks, tests, builds, and previews. Keep dependencies and caches in `.local/`
  inside this project.
- Read each project's `project.py` and preserve reported measurements and
  assumptions. Native configurations own standard part dimensions.
- Cabineteer is the foundation. Its tracked source is in `vendor/cabineteer`.
  Record upstream provenance and keep engine edits visible in the repository.
- Step 1 is a bare cabinet. Drawers, overlay fronts, EB20 runners, and bracing
  are step 2. Carcass Dominoes are fixed at 6×40 mm.
- Never invent hardware or machining facts. Keep unverified choices visible
  and prevent a manufacturing-ready claim while they remain unresolved.
- Run Buratino `check` and `test`. Inspect a real
  preview when changing geometry or viewing assets.
