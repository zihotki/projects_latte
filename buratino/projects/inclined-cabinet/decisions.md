# Simple cabinet draft

The user requested a bare cabinet before implementing drawers. The survey
records the reported available space. The design file contains provisional
dimensions and materials. Change the design file, then run the build command.

All generated documents are drafts. Confirm fitting allowance, measured stock,
back construction, edge treatment, support, and verified 6×40 Domino machining
before cutting. No machining depths or Domino quantities are invented here.

The later drawer project retains four equal-height overlay fronts, EB20
runners, nominal 16 mm drawer sides, and planned manual bottom bracing.
