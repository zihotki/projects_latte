# Archive

The former project at `projects/real-assembly` is superseded by the current
native project at `projects/real-assembly-native`.

This archive keeps the historical source and its build snapshots. It is not a
runnable project contract and is excluded from active examples and tests.

`obsolete-local-state/` retains retired runtime files and historical agent
notes. It is ignored by Git and is not used by current commands. New project
outputs stay under `projects/NAME/build/` and `projects/NAME/exports/`.
